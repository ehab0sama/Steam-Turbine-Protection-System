# Steam Turbine Protection System  
### PID Control vs Open-Loop Control

Dynamic MATLAB simulation for protecting LP steam turbines from wet-steam conditions using PID feedback control and XSteam thermodynamic modeling.

---

## Project Features

- Reheat Rankine-cycle simulation
- Steam quality monitoring
- PID-based turbine protection
- Open-loop vs PID comparison
- Real steam properties using XSteam
- Disturbance-based safety analysis
- Engineering performance metrics

---

## Main Objective

Protect the low-pressure steam turbine from dangerous moisture conditions caused by:

- Condenser pressure rise
- Boiler degradation
- Load disturbances
- Steam-flow variations

---

## Technologies Used

- MATLAB
- XSteam
- PID Control
- Thermodynamics
- Dynamic System Simulation

---

## Results

The PID controller significantly improved:

- Steam quality stability
- Turbine safety
- Disturbance rejection
- Recovery performance

compared to conventional open-loop operation.
